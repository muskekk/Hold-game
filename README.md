# Hold Game

### **Overview**

Hold Game is a simple interactive lighting game where you control different light sources by pressing, holding, and dragging.

The goal is to turn on a light and lock it in place.

### **How to Play**

1. Choose a light source from the navigation menu:

   * Candle
   * Lantern
   * Bulb
   * Campfire

2. Press and hold the selected light source.

3. While holding it, a lock icon will appear above the object.

4. Drag the light source toward the lock icon.

5. When the lock icon changes to indicate that it is ready, release the pointer.

6. If the light is successfully locked, the light will remain on.

### **Turning the Light Off**

Click or tap anywhere outside the light object to turn the light off.

If the light has not been locked and you release the pointer without reaching the lock, the light will also turn off.

### **Light Sources**

### ***Candle***

A warm light with a flickering flame.

### ***Lantern***

A bright yellow light with a directional beam.

### ***Bulb***

A steady and wide light with no flickering.

### ***Campfire***

A strong red and orange light with a flickering flame.

### **Controls**

* **Press and Hold:** Turn on the selected light.
* **Drag:** Move toward the lock target.
* **Release:** Lock the light if you are over the lock target.
* **Click Outside:** Turn the light off.
* **Navigation Buttons:** Switch between light sources.

### **Objective**

The main objective is to successfully activate and lock the selected light source.
